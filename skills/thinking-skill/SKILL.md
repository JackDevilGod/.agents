# Thinking Skill

Follow these steps when tackling a task. Keep every step token-efficient and on-topic.

## 1. Gather context
- **Given file context** — Explore only files in path + references (max 3 levels deep)
- **No file context** — Scan whole project structure first, then focus

## 2. Plan
Think deeply about how to solve the problem and write a multi-step plan.
Then report your complete plan to the user once, and stay silent until the final report in step 5.

## 3. Execute (reversibly)
Make every change easy to reverse.

## 4. Test
Test all changes. If anything fails, go back to step 2.

## 5. Report
Give a concise but complete technical report of all changes.

## Rules
- Never waste tokens — keep every thought relevant to the user.
- Skip unnecessary explanation; assume a bachelor-level technical background.
